## 二、跨天追问链（面试官会怎么往下挖）

**① "你怎么保证代码质量？"**
分层策略 → 单测/集成各管什么 → 举 fake repo 的具体例子 →
→ *"fake 和真实 repo 行为不一致怎么办？"* 契约测试：同一套测试跑两个实现 →
→ *"那你还测什么？"* 测 service 的编排逻辑，不测 SQL 语法

**② "覆盖率 91% 了为什么还出事？"**
执行≠验证 → 举 #07/#08 的实例 →
→ *"那看什么指标？"* 变异测试 + 断言的**判别力**（选例要落在两种实现会分叉的输入上）→
→ *"变异测试有什么缺点？"* 慢（本项目 5 个变异体 13s）、等价变异体误报、只覆盖你写的那些变异算子

**③ "CI 红了、你本地绿，怎么查？"**
先分清**推送失败 vs CI 失败** → 看失败步骤耗时（秒退＝极早崩）→ 列环境差异清单：依赖版本 / 环境变量 / 时间与时区 / 排序与哈希 / 文件路径大小写 →
→ *"这次具体是什么？"* `.env` 未入库 → import 期 ValidationError → 0 收集

**④ "异步代码怎么测？"**
TestClient 不够（三项能力缺失）→ `AsyncClient(transport=ASGITransport(app))` →
→ *"异步测试有什么特有的坑？"* 漏 `await` 测试照样绿 → `-W error::RuntimeWarning` 进 CI

**⑤ "外部服务不稳定怎么测？"**
respx 在 Transport 层拦 → 三种响应：正常/错误码/超时（`side_effect`）→
→ *"只断言返回够吗？"* 不够，要断言**请求侧**（`respx.calls.last.request` 的 path / headers / body）→
→ *"降级路径测了吗？"* 降级后**不能缓存**、恢复后要能重新请求（#10 坑 4）

## 三、30 秒答案集（W4 版）

1. **为什么要分层测试？** 定位精度 + 能断言"没发生"，不是"快"。
2. **什么该 mock？** 被测逻辑之外、慢或不确定的东西；被测逻辑本身绝不替换。
3. **fake 和 mock 的区别？** fake 有真实业务行为，mock 的行为全是你假设的。
4. **怎么断言"没发生"？** spy 账本，过滤到具体方法名，`[c for c in calls if c[0]=="delete"] == []`。
5. **TestClient 有什么局限？** 不能直接 await service、不能用 async fixture、不能异步依赖替换。
6. **异步测试最容易假绿在哪？** 漏 `await`——协程不执行，只有 RuntimeWarning。
7. **怎么测 token 过期？** 冻结时间→签发→快进→验证，两段式，不真等。
8. **怎么测外部 HTTP？** respx 拦 Transport，响应侧 + 请求侧都断言。
9. **覆盖率能证明什么？** 只证明"这行被执行过"，不证明"行为被验证过"。
10. **怎么证明测试有杀伤力？** 变异测试：改一行，测试必须红；存活即漏洞。
11. **门禁为什么用脚本？** exit code 是唯一语言，人看报告会漏。
12. **测试为什么要自包含？** 不依赖机器上碰巧存在的 `.env`/文件/时间，否则 clone 下来就红。

## 五、本周踩坑实录（亲手炸过的才记得住）

| 坑 | 场景 | 教训 |

## 六、可讲的故事（面试素材，按杀伤力排）

- **"覆盖率 91% 的全绿套件，抓不住一个已经存在的 spec 违反。"** 我做了个实验：把 `test_split_text.py` 整个删掉，覆盖率只从 92.43% 掉到 92%，但变异得分从 2/5 直接归零。删掉 5 个真测试，覆盖率几乎不动，杀伤力掉 100%。
- **"我的 4 个测试全绿，但把'先删后鉴权'的 bug 植进去照样绿。"** 因为测试只断言了抛异常，没断言数据还在。从那以后我写测试先问一句：**这条测试能杀死哪种 bug？**
- **"我机器上是好的"——CI 3 秒全红。** 根因是 `.env` 被 gitignore、从未入库，CI 上 `create_app()` 在 import 期就抛 `ValidationError`，一条测试都没跑起来。我没在 CI 里塞环境变量把它按绿，而是让测试套件自带配置——因为病是"测试不自包含"，不是"CI 缺一个变量"。
- **"我让 AI 写了一套测试，四条全绿；我自己找出三条假测试。"** 永真断言、镜像断言、stub 换掉被测逻辑——AI 时代的核心能力不是写测试，是**看出这套测试是假的**。

## 每天的核心问题（学完必须能答）

### W2-D1 迭代器协议
- `for` 循环的底层到底做了什么？（`iter()` → 循环 `next()` → 捕获 `StopIteration`）
- 可迭代对象（Iterable）和迭代器（Iterator）的区别？为什么 list 不是迭代器？
- 为什么迭代器只能走一遍？（结合你 Day7 刚见过的"生成器耗尽"）

### W2-D2 生成器
- `yield` 暂停时函数的状态存在哪？（和闭包同源）
- 生成器 vs list 的内存差异，什么量级？（本周要实测出数字）
- 为什么 SSE 流式输出必须用生成器？（对照 kb-service 的 `answer_stream`）

### W2-D3 装饰器进阶
- `@decorator` 和 `@decorator(...)` 的区别？（带参装饰器是"三层函数"）
- 装饰器在**什么时候执行**？（结合 Day4 踩过的 `@lru_cache` 加载即执行）
- 闭包变量绑定坑：`lambda: i` 循环里为什么全是最后一个 i？怎么修？

### W2-D4 异常体系
- `raise X from Y` 和裸 `raise X` 的区别？（`__cause__` vs `__context__`）
- "异常分层"怎么设计？为什么 repo 抛的异常不该直接飞到 HTTP 层？
- `except Exception as e: raise RuntimeError(...)` 会丢什么？（Day7 第四档 P2 的正式版）

### W2-D5 魔术方法
- `__repr__` 和 `__str__` 的区别？只写一个该写哪个？
- 定义了 `__eq__` 不定义 `__hash__` 会发生什么？（类会变 unhashable！）
- `@property` 什么时候用，什么时候是过度设计？

## 阶段任务预览（W2-D6）：`stream_utils`

为 W14 的 SSE 提前造零件，纯 Python、零三方依赖：

1. `chunk_text(text, size, overlap)` —— 生成器版分块（对照 doc_service 里的 `split_text`，体会"生成器版"省在哪）
2. `paged(items_iter, page_size)` —— 把无限迭代器切成"页"的迭代器（分页不是 slice，是 itertools 思想）
3. `Cursor` 类 —— 游标对象：支持 `__repr__` / `__eq__` / `__len__`，可比较可打印（D5 的魔术方法落地）

验收方式照旧：自建验收器 + ruff 全绿 + 第四档 #03（埋坑版 stream_utils）。

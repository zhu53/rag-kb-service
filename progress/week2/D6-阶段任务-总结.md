## 2. `read_chunks`（流式读取的实现原型）

```python
def read_chunks(path: str, chunk_size: int = 8192) -> Iterator[str]:
    with open(path, encoding="utf-8") as f:
        while chunk := f.read(chunk_size):     # 空字符串即 EOF
            yield chunk
```

- `f.read(n)` 返回 `""` 表示读完——这是循环的退出条件（不能用 `None`，见 D1 §1.2 的"信号撞车"）。
- `with` 在生成器里有效：生成器被 GC 或 `close()` 时正确关文件。
- 用 walrus（`:=`）少一行；`chunk_size` 默认 8KB 与常见 IO 块大小对齐。

### 面试问法："大文件怎么读不进内存？"

**30 秒答案**："用生成器一块一块读。`f.read(size)` 每次返回固定大小的块，读到空字符串说明结束，每次 yield 出去后内存里只有一块，所以 10GB 文件也只占几 KB。关键是别用 `read()` 或 `readlines()`——那是把整个文件物化到内存。这个模式放到 LLM 上就是流式输出：模型吐一个 token，我就 yield 一次，用户一秒内能看到首字。"

## 3. `Cursor`：为什么它能反复遍历（今天最重要的设计）

```python
class Cursor:
    def __init__(self, items: list[Any]) -> None:
        self._items = items
        self._pos = 0

    def __iter__(self) -> "Cursor":
        return Cursor(self._items)      # ← 返回新实例，_pos 天然从 0 开始

    def __next__(self) -> Any:
        if self._pos >= len(self._items):
            raise StopIteration
        value = self._items[self._pos]
        self._pos += 1
        return value

    def __len__(self) -> int:
        return len(self._items)

    def __getitem__(self, index: int) -> Any:
        return self._items[index]

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Cursor):
            return NotImplemented
        return self._items == other._items

    def __hash__(self) -> int:
        return hash(tuple(self._items))
```

### 设计要点

- Cursor **同时是** Iterable（有 `__iter__`）和 Iterator（有 `__next__`）。
- 但每次 `for` 都**造一个新的 Cursor** 去遍历，原对象 `_pos` 不动 → **可反复遍历**。
- 这正是 list 的原理：list 自己不数数，每次 `iter(lst)` 新建一个 `list_iterator`。
- 对照 D1 的 `Countdown`：那是一次性光标（`__iter__` 返回 `self`）；Cursor 是可复用序列——**两者的差别就在 `__iter__` 返回谁**。

**一句话结论**：**`__iter__` 返回 `self` → 一次性；返回新对象 → 可复用。**

### 面试问法："怎么实现一个可以反复遍历的自定义容器？"

**30 秒答案**："关键是分离'容器'和'游标'。容器实现 `__iter__` 时返回一个新建的迭代器对象，游标状态放在那个对象里，这样每次 for 都是全新游标，原容器状态不变——list 就是这么做的。如果 `__iter__` 返回 `self`，游标就长在容器身上，走一遍就空了。我的实现里 Cursor 既当容器又当游标，靠 `__iter__` 返回新实例来保证可重复遍历。"

## 4. `paginate`：不能 `list()` 的理由

```python
def paginate(items: Iterable[T], page_size: int) -> Iterator[list[T]]:
    page: list[T] = []
    for item in items:
        page.append(item)
        if len(page) == page_size:
            yield page
            page = []
    if page:                 # 尾页（别漏）
        yield page
```

**为什么不能 `list(items)`**：`items` 可能是无限生成器（`fib()`），`list()` 会永远跑下去直到 OOM。
**正确姿势**：逐个 `next`，攒满一页就 `yield`，内存上限 = 一页。

**异常处理**：只写 `except StopIteration`（真实项目里用 `next(it, sentinel)` 或 for 循环即可）；`except Exception` 会把上游真异常当"取完了" → **静默少数据**（第四档 #03 的 P4 就是它）。

### 面试问法："分页处理一个可能是无限的数据源，怎么写？"

**30 秒答案**："不要先物化。用生成器逐条取，攒满一页就 yield 出去，然后清空继续攒，内存占用只跟页大小有关。如果数据源是无限流（比如实时事件），这个模式天然适用；如果先 `list()` 就会永远跑不完。另外异常要只捕获 `StopIteration`，用 `except Exception` 会把上游真正的错误当成'数据取完了'，结果是静默少数据——这类 bug 在监控里看不出来，只能靠代码审查。"

## 5. 首版踩的三个坑（全部自己修复）

| # | 坑 | 症状 | 根因与修法 |
|---|---|---|---|
| 1 | `Cursor = Cursor.__new__()` | UnboundLocalError | **局部变量遮蔽了类名**（右边找的是未赋值的局部变量）；造实例直接调类：`return Cursor(self._items)` |
| 2 | `__eq__` 条件装反 | 相同元素判为不等 | 守卫语义是"不是自家人才拒绝"：`if not isinstance(...)` |
| 3 | `__next__` 用 `>` | IndexError（潜伏雷） | `_pos == len` 时也要停：边界用 `>=`，与 D1 Countdown 的错同族 |

**验收器的一个细节**：第 8 项先测 `__iter__`，坑 3 被 UnboundLocalError 挡住没爆——**修 bug 时要看"还有没有同族雷"，不要只修报错的那一个**。

## 6. 验收器设计的两个技巧（以后自建验收器复用）

1. **无限生成器测试**：`paginate(fib(), 4)` 配 `itertools.islice(..., 2)` 只取前两页——既验证"没把无限流 list 进内存"（会卡死=暴露），又不会让测试本身挂死。
2. **每项独立 try/except**：一项挂了不连坐，失败信息带异常类型和实际值，直接指向修复方向。

## 7. 追问链（面试深挖预演）

| 起点 | 追问 | 你要能答 |
|---|---|---|
| 可复用容器 | list 为什么能反复遍历？ | 每次 `iter()` 新建 list_iterator；容器本身无游标状态 |
| `__iter__` 返回 self | 为什么不好？ | 容器承担游标状态，走一遍就空；并发遍历还会互相干扰 |
| 分页 | 尾页会漏吗？ | 会——循环结束后要 `if page: yield page` |
| 无限流 | 怎么只取前 N 页？ | `itertools.islice`；不要 list |
| 异常 | 为什么只捕 StopIteration？ | 其他异常是真错误，捕了会静默少数据 |
| 流式 | 中间层缓冲怎么办？ | `X-Accel-Buffering: no`、禁用 gzip 缓冲、客户端用 EventSource/ReadableStream |
| 背压 | 生产者比消费者快怎么办？ | 生成器天然背压（消费者 next 才产）；异步下用 `asyncio.Queue(maxsize)` |
| 资源 | 生成器没读完就退出？ | 调用 `close()` 或依赖 GC；`with`/`try-finally` 保证释放（连接、文件） |

## 10. 30 秒答案集（考前速背）

1. **可复用容器怎么实现** → `__iter__` 返回新游标对象，容器自身不留游标状态。
2. **一次性 vs 可复用** → `__iter__` 返回 self vs 返回新实例。
3. **分页为什么不能 list** → 可能是无限流，内存爆；逐条取、攒满即 yield。
4. **漏尾页** → 循环后补 `if page: yield page`。
5. **f.read(n) 结束条件** → 返回 `""`。
6. **分页异常** → 只捕 `StopIteration`；捕 Exception 会静默少数据。
7. **流式中间层** → 关缓冲（`X-Accel-Buffering: no`）。
8. **生成器背压** → 消费者不 next 就不生产。

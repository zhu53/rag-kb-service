## 2. ⭐ 协议全景表（W2 的核心认知，一张表记完）

> **Python 对象的行为全是协议约定的：实现协议 = 获得语法。** W2 五天分别讲了其中一族。

| 想获得的能力 | 实现的协议 | 讲在哪天 |
|---|---|---|
| `for x in obj` | `__iter__` + `__next__`（`raise StopIteration` 结束） | D1 |
| 惰性序列/流式 | `yield`（生成器，自动实现迭代器协议） | D2 |
| 函数前后插入逻辑 | `__call__` + 闭包（装饰器） | D3 |
| 被 `except` 捕获、被翻译层识别 | 继承 `Exception` 家族 + 携带 `code`/`http_status` | D4 |
| `print(obj)` / `repr(obj)` | `__str__` / `__repr__`（str 缺失退回 repr） | D5 |
| `a == b` / `hash(a)` / set / dict key | `__eq__` + `__hash__`（**联动**） | D5 |
| `len(obj)` / `obj[k]` / `bool(obj)` | `__len__` / `__getitem__` / `__bool__` | D5 |
| `with obj` | `__enter__`/`__exit__` 或 `@contextmanager` | Day5（W1） |
| `obj(...)` 当函数用 | `__call__`（类装饰器、partial） | D3 |

**一句话总纲**："这些都不是魔法，是双下划线命名约定 + 解释器在固定语法点查固定方法名。"

## 3. 这周真正长出来的三样东西（面试可讲）

### 3.1 协议思维

从"记住函数怎么用"升级到"知道解释器在什么时机查哪个名字"。收益是**遇到新框架能猜实现**：看到 `@app.get(...)` 就知道是"注册 + 返回原函数"；看到 `async with` 就知道找 `__aenter__`。

### 3.2 流式输出的地基

`read_chunks`（边读边吐）+ `paginate`（切页）+ `Cursor`，就是 SSE 的全部零件预演。
看到 `StreamingResponse(answer_stream(...))` 时你知道：那是一个"每被 next 一次吐一小截、吐完 StopIteration"的生成器。

**面试讲法**："流式响应本质是生成器 + chunked 传输。生成器每 yield 一段，框架就 flush 一段给客户端，所以首字节延迟从十几秒降到一秒内。要注意中间层缓冲——Nginx 默认会攒，得加 `X-Accel-Buffering: no`。"

### 3.3 验证能力（本周最大收获）

第四档三连 **3/4 → 4/4 → 3/4**，零症状坑（死注解、缺 `__hash__`）开始能靠读代码定位。
**"AI 给错了，我能看出来"** —— 这正是 W1 定下的手写标准，本周开始兑现。

## 4. 方法论沉淀（写给自己）

1. **讲解密度按"弄懂弄全"定，不按概念个数定**（本周经三次修正才对齐：≤3 不是上限也不是底线，唯一标准是讲透）。
2. **先讲后练，不考没学过的**（D1 教训：AI 误判"你学过 for 底层"）。
3. **实测先于结论，且结论可能连翻两次车**（小整数缓存：字面量合并、常量折叠，`int("257")` 才复现）。
4. **易混概念写成三行对照表**（NotImplemented 三兄弟、== vs is；单点记忆必混）。
5. **dunder 方法名永远 IDE 补全**（`__int__` 事件，连描述 bug 时都又拼错）。
6. **验收器要喂极端输入**（无限生成器防卡死；smoke 全绿 ≠ 正确）。

## 5. 面试题库（15 题速答）

| # | 问题 | 30 秒答案要点 |
|---|---|---|
| 1 | for 循环底层 | `iter()` → `next()` → 捕 `StopIteration` |
| 2 | 为什么用异常表示结束 | 数据可能有合法 None，信号与数据会撞车 |
| 3 | Iterable vs Iterator | 只有 `__iter__` vs 两者都有；后者单光标只能走一遍 |
| 4 | 生成器省多少内存 | 实测 200 万元素：77MB → 0MB；能表示无限序列 |
| 5 | yield vs return | 暂停 vs 结束；可无限次 vs 一次；调用时不执行 vs 立即 |
| 6 | 装饰器原理 | 收函数返函数；`@` = 赋值语法糖；靠闭包 |
| 7 | 忘写 wraps | 签名丢失（`__wrapped__` 没有）→ FastAPI 全 422 |
| 8 | 闭包经典坑 | 捕获变量不捕获值 → `lambda: i` 全返回 2 |
| 9 | 异常链 | `raise X from y` → `__cause__`；不写也有 `__context__` |
| 10 | 自定义异常体系 | 基类带 code/http_status/message；service 只抛领域异常，最外层翻译 |
| 11 | except Exception 风险 | 业务错误与程序 bug 混锅，403 静默变 500 |
| 12 | print 查找顺序 | 先 `__str__`，缺失退回 `__repr__`；容器内部用 repr |
| 13 | `__eq__` 后不可哈希 | `__hash__` 被自动置 None；补同字段 `hash()` |
| 14 | NotImplemented vs NotImplementedError | 协商信号（返回值，无括号）vs 必须子类实现的异常 |
| 15 | is 什么时候用 | 只用于 None/哨兵；比值永远 `==`（小整数缓存是碰巧对） |

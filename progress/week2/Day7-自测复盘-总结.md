## 2. 三条概念纠错（面试必背，全部曾答反）

### 2.1 `print` 的回退方向 —— str 优先

```
print(obj)  →  先找 __str__  →  没有才退回 __repr__
```

**方向是 str 优先**。"只写 repr 也够用"是因为 **str 缺失时退回 repr**，不是 repr 优先。

> 面试话术："print 和 f-string 先调 `__str__`，没定义才退到 `__repr__`；而调试器、日志、容器内部显示直接调 `__repr__`。所以只写 repr 就能同时满足两种场景。"

### 2.2 `==` 与 `is`

| | `==` | `is` |
|---|---|---|
| 问的问题 | 相等吗？（语义由类型 `__eq__` 定义） | 同一个对象吗？（恒比 id，**不可重载**） |
| 内置类型 | 比值（list/str/int 都定义了 `__eq__`） | 通常 False |
| 自定义类未定义 `__eq__` | **退回身份比较** → 内容相同也 False | False |
| 正当用途 | 比值 | **只有 `x is None` / 哨兵对象** |

**小整数缓存陷阱**（实测三轮才复现，值得当故事讲）：CPython 预建 `-5~256`，区间内 `is` 碰巧 True；且同一脚本里相同字面量会**编译期合并**、`256+1` 会被**常量折叠**——想让 257 分家必须 `int("257")` 在运行时创建。

**结论**：**比值永远用 `==`；`is` 只用于 `None` 和哨兵。** 依赖小整数缓存是"碰巧对"，不是"正确"。

### 2.3 三个"不"字辈（Q11 混淆过）

| 名字 | 意思 | 谁用 |
|---|---|---|
| `return NotImplemented` | 协商失败信号，"你去问别人"（**无括号**，单例对象） | `__eq__` 等双目运算 |
| `raise NotImplementedError` | 此方法必须由子类实现 | 抽象基类/骨架代码 |
| `raise StopIteration` | 迭代到头了 | `__next__` |

> 面试话术："NotImplemented 是返回值不是异常，表示我不认识对方、请解释器去问另一方；NotImplementedError 是异常，表示抽象方法没实现；StopIteration 是迭代结束信号。"

## 3. 补强点（每条都能当面试题）

### 3.1 Q1：结束信号为什么不能返回 `None`

数据里可能合法地存在 `None`（`[1, None, 3]`），用它当结束信号会和真实数据撞车。**异常走独立通道**，天然分流"正常值"和"结束"。

### 3.2 Q4：什么时候该用 list 不用生成器

- 需要**多次遍历**（生成器只能走一遍）
- 需要**随机访问/切片**（`it[3]`、`it[1:5]`）
- 需要 `len()`
- 数据量小（省的那点内存不值得牺牲 API）

实测：200 万元素 list ≈ 77MB，生成器 ≈ 0MB。

### 3.3 Q5：忘加 `@wraps` 的真实后果

FastAPI 用 `inspect.signature()` 读签名做参数校验。不 `wraps` 时它看到的是 `wrapper(*args, **kwargs)` → 把 `args`/`kwargs` 当成必填 query 参数 → **全部接口 422**。

### 3.4 补课 1：`__hash__` 联动（唯一零症状坑）

定义 `__eq__` 后 Python 自动 `__hash__ = None`。

**为什么**：相等语义变了，默认按地址算的 hash 会让"相等的对象 hash 不同"，破坏 dict/set 的不变式。**故意禁用是保护，不是 bug**。

**补救**：`__hash__` 与 `__eq__` 用**同一批字段**（如 `hash(tuple(self._items))`）。

**延伸**：`@dataclass` 默认 `eq=True, frozen=False` → 不可哈希；`frozen=True` 才生成 `__hash__`。pydantic 模型同理（BaseModel 默认不可哈希，`frozen=True` 可哈希）。

### 3.5 Q12：`f.read()` 内存炸弹

小文件零症状 → **smoke 全绿 ≠ 代码正确**。测试数据量要模拟生产规模，否则"能跑"只是巧合。

## 4. 面试问答：这 12 题如果被问到（速答版）

| 问题 | 30 秒答案要点 |
|---|---|
| for 循环底层？ | `iter()` → `next()` → 捕 `StopIteration` |
| 为什么用异常表示结束？ | 数据可能有合法 None，信号会撞车 |
| Iterable vs Iterator？ | 只有 `__iter__` vs 两者都有；后者只能走一遍 |
| 生成器省内存多少？ | 实测 200 万元素：77MB → 0MB |
| 生成器和迭代器关系？ | 生成器是 yield 函数，自动实现迭代器协议 |
| 装饰器原理？ | 收函数返函数；`@` = 赋值语法糖；靠闭包 |
| 忘写 wraps 会怎样？ | 签名丢失 → FastAPI 全 422 |
| 异常链怎么保留？ | `raise X from y` → `__cause__`；不写也有 `__context__` |
| print 的查找顺序？ | 先 `__str__`，缺失退回 `__repr__` |
| 未定义 `__eq__` 时 `==`？ | 退回身份比较（比 id） |
| 定义 `__eq__` 后能进 set 吗？ | 不能（`__hash__` 变 None）；补同字段 hash |
| `is` 什么时候用？ | 只用于 `None`/哨兵；比值用 `==` |

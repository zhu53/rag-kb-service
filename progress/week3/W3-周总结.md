## 三、30 秒答案集（W3 版，与 D7 复盘互补）

1. **为什么用 src 布局？** 平铺布局会让你测的代码和用户装的不是同一份；src 布局强制"安装后才能 import"，测试的就是装出来的包。
2. **[project.scripts] 干了什么？** 安装时生成包装脚本 `kbcli = "kbcli.cli:main"`；main() 的返回值就是进程退出码（None=0），CI 靠它判断成败。
3. **secrets 怎么管？** `.env` 真值不进 Git（gitignore），`.env.example` 模板进 Git；生产密钥走环境变量注入。
4. **手写 retry 的循环语义？** times=3 = 总共试 3 次；成功 return 即收工；全失败 raise last_exc（最后一次）。
5. **LRU 为什么用 OrderedDict 不用 dict+list？** move_to_end 和 popitem(last=False) 都是 O(1)；list 删除是 O(n)。
6. **删除后不清缓存会怎样？** 幽灵读——缓存尸体绕过 NotFound 判定返回已删数据。

## 五、本周踩坑实录（亲手炸过的才记得住）

| 坑 | 场景 | 教训 |
|---|---|---|
| set 建成 dict | `record = {a, b, c}` 只有一袋值 | 有键值对才是 dict |
| `.hex` 丢了 | `uuid4()[:8]` 对 UUID 切片 | UUID 对象先转字符串 |
| 键名分裂 | create 存 owner_id、筛 value["owner"] | 数据形状先定死，全项目统一 |
| 属性注解不求对 | `self._data: [str, ...]` 是 list 字面量 | 要写 `dict[str, ...]` |
| 相对导入 | `from error import` 只有撞目录才能对 | 包内兄弟模块用 `.error` |
| 盖章丢失 | filter 里读出来没挂 record | Formatter 找不到属性 → Logging error |
| ContextVar.get 传参 | `get("trace_id")` 传的是缺省值 | 参数不是变量名 |
| put 覆盖写 | 赋值关进 else → 只挪位不更新 | 条件只管挪位/计数，赋值无条件 |
| **缓存绕过鉴权** | 命中缓存直接 return，跳过 owner 校验 | **缓存层不能 bypass 业务规则**（生产级事故形状） |
| 进程寿命 | CLI 每次冷启动，缓存证据只能同进程拍 | 缓存活多长取决于进程活多长 |

> 默认安装位置：`C://Users//acer-pc//.local//bin`（uv 本体）、`AppData\Local\uv\cache`（缓存，最占空间）。>   
> **详细路径说明、迁移到 D 盘、4 个 Windows 常见坑 → 见同目录 `uv安装说明.md`**。

## Day3 · Git 进阶（3h）

### 3.1 必学命令（60min）

```bash
git switch -c feat/w1-exercise     # 开分支
git commit --amend                 # 改最近一次提交（不改历史时用）
git rebase -i HEAD~3               # 合并/改写本地提交（交互式，练一次）
git log --oneline --graph --all    # 图形化看历史
git diff --staged                  # 看暂存区差异
git restore --staged <file>        # 撤销暂存
git stash / git stash pop          # 临时存档
```

### 3.2 Conventional Commits（40min）

```
<type>(<scope>): <subject>

type: feat | fix | docs | style | refactor | test | chore | perf
```

写 5 条提交，覆盖 `feat` / `fix` / `test` / `docs` / `chore` 各一条。**为什么要规范**：后面 CI 要按 type 自动生成 changelog，面试也能体现工程素养。

### 3.3 写你们的 `.gitignore` 与 pre-commit（80min）

`.gitignore` 已给好。现在配 pre-commit：

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.8.4
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format
```

```bash
uv add --dev pre-commit
uv run pre-commit install
uv run pre-commit run --all-files
```

**验收**：故意写一行 `x=1` （缺空格 + 未使用变量），`git commit` 被拦截，ruff 自动修好。

## Day4 · 标准库速通（上）（3h）

> 方法：**看文档 + 默写**。每个模块 15 分钟看官方文档 Tutorial 段，然后合上文档默写。

| 模块            | 必须掌握                                                     | 默写练习                                   |
| ------------- | -------------------------------------------------------- | -------------------------------------- |
| `pathlib`     | `Path` 的 `/` 拼接、`read_text`、`glob`、`mkdir(parents=True)` | 遍历目录下所有 `.py` 文件，按大小排序输出               |
| `logging`     | logger 层级、handler/formatter、`extra`、`exc_info`           | 写一个带文件轮转（`RotatingFileHandler`）的日志配置   |
| `json`        | `dumps(ensure_ascii=False)`、`default=` 处理不可序列化对象         | 让 `datetime` 对象能直接 json 序列化            |
| `dataclasses` | `field(default_factory=)`、`frozen=True`、`__post_init__`  | 写一个不可变配置类，构造时校验                        |
| `collections` | `defaultdict` / `Counter` / `deque` / `namedtuple`       | 统计一段文本词频 Top10，用 `Counter.most_common` |
| `itertools`   | `chain` / `groupby` / `islice` / `pairwise`              | 把两个列表交替合并                              |

**坑点**：`dataclass` 的 `mutable default` 会被 Python 直接拦下报错（`ValueError: mutable default...`）—— 这是**你必须能解释**的经典陷阱，答案是 `field(default_factory=list)`。

**产出**：`progress/week1/stdlib_practice.py`，12 个练习各一个函数，全部带类型注解。

## Day5 · 标准库速通（下）（3h）

| 模块           | 必须掌握                                                          | 默写练习                                  |
| ------------ | ------------------------------------------------------------- | ------------------------------------- |
| `typing`     | `Optional` / `list[str]` / `Literal` / `Protocol` / `TypeVar` | 用 `Protocol` 定义"可存储对象"，让两个不同类都满足      |
| `asyncio`    | `gather` / `TaskGroup` / `Semaphore` / `sleep` / `run`        | 并发请求 10 个 URL，限制并发为 3                 |
| `argparse`   | `add_argument` 的 `type`/`choices`/`nargs`、子命令                 | 写个 `--verbose` 开关 + `--count` 参数的 CLI |
| `functools`  | `wraps` / `lru_cache` / `partial` / `reduce`                  | 写一个带缓存的斐波那契，并打印缓存命中情况                 |
| `contextlib` | `contextmanager`、`suppress`                                   | 写一个计时上下文管理器                           |
| `enum`       | `StrEnum` / `IntEnum` / `auto()`                              | 用 `StrEnum` 定义文档状态                    |

**重点理解**（面试高频）：

- `asyncio.gather` 和 `TaskGroup` 的区别 → TaskGroup 有结构化并发，一个失败会取消其余。
- `Protocol` 和 ABC 的区别 → Protocol 是**结构化子类型**（鸭子类型 + 类型检查），不需要显式继承。
- `@wraps` 不加会怎样 → 被装饰函数的 `__name__` / `__doc__` 丢失，FastAPI 路由名会全变成 `wrapper`。
